# T-PM 产品开发管理

## 新需求/需求变更流程

当用户输入需要新增一个【需求】或者修改已有的【需求】时，使用下面的流程来管理它：

1. 确认目前【需求】是否已经存在，存在则判断是否需要修改需求。
2. 更新或者创建【需求】。
3. 检查是否引入的新的【概念】，或对已有的【概念】有更新。
4. 更新或创建【用户故事】。
5. 更新或者创建【流程】，并且配置其关联的【方法】为【待处理方法】。

## 开发流程

当出现一个【待处理方法】时，使用下面的流程来管理它：

1. 确认哪个【模块】需要承接这个【流程】
2. 确认是否需要新增或者修改已有【方法】
3. 更新【方法】所对应的代码
4. 完成【测试】
