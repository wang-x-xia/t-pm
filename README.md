# TTT-产品管理

## 目标

一个全能的产品管理系统，从用户故事开始，到代码实现、测试、发布，形成一个由确定的流程主导的，人和AI共同参与的文档系统。

## 背景

对于一个已经持续了若干年的项目，对于一些即将由AI生成的大型项目，始终有一个问题萦绕在我脑中，就是如何有序的整理新的需求。

受限于旧时代的桎梏，很多知识的丢失已经变成了一个无法回避的问题。

毕竟，对于一个人而言，现实的问题是：

1. 人类的本身的智慧无法维护一个拥有了数千个用户故事的项目。
2. 人类“擅长”的，是定义一个模糊的需求，或者实现一个确切的功能。
3. 人类需要的，是对产品的掌控。

因此，对于一个“全能”的产品管理系统而言，首先是需要确定性：

1. 在一个特定的时间，产品的范畴是确定的。
2. 对于一个特定的功能集合而言，其负责的权能是确定的。
3. 对于最终生成的代码，其功能是确定的，其验证方案，是确定的。
4. 在整体的流程上，是人类可以理解的，确定的。

## 核心目标

第一步：

提供一系列内置的概念，并基于这些概念生成一个确定的软件研发流程。
在这些步骤中，融合了人类的智慧和AI的能力，形成一个有序的、确定的流程。
包括自顶至底的需求分析、模块拆分、功能设计，以及自底至上的代码实现、模块验证与产品反馈。

第二步：

支持用户自定义概念，以及自定义流程，适配某些公司本身的组织结构。

第三步：

支持AI驱动的流程优化。
